# Osamah AlBahnasi — Portfolio

Personal portfolio site for Osamah AlBahnasi — SAP-certified junior consultant and software engineer.

Built with:

- [Next.js](https://nextjs.org) (App Router)
- [Motion for React](https://motion.dev) — scroll reveals, cursor-reactive spotlight, magnetic buttons, 3D tilt cards
- [Tailwind CSS v4](https://tailwindcss.com)
- [Phosphor Icons](https://phosphoricons.com)

## Getting started

```bash
git clone https://github.com/OzyCode/ozy-portfolio.git
cd ozy-portfolio
```

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```
